## DiskOUT v0.4.2 — 앱 안 언어 스위처

이번 버전은 작은 사용성 개선입니다.

### 새로운 기능

- **앱 안 언어 변경**: 메뉴바 메뉴 "🌐 언어 변경…" 또는 환경설정 → 일반 → 언어 dropdown 에서 DiskOUT 만의 표시 언어를 별도로 선택할 수 있습니다.
  - 옵션: **시스템 따라가기 / 한국어 / English**
  - macOS 자체는 영어로 쓰면서 DiskOUT 만 한국어로 보고 싶은 경우 (또는 반대) 지원
  - 언어 변경 시 DiskOUT 만 재시작되며, 다른 데이터 (제외 목록, 설정) 는 그대로 유지

### 변경

- 제작자 표기 정정: yongZa → **LIMOD** (About 탭, 푸터 등 표시용 항목).
  - Bundle ID (`com.yongza.ejectdrives`) 는 사용자 데이터 호환성을 위해 그대로 유지 — 업데이트 후에도 기존 설정 (자동 실행, 제외 목록, 알림 설정) 모두 보존됩니다.

### 시스템 요구사항

- macOS 13.0 이상 (Apple Silicon 네이티브, Intel 동작)
