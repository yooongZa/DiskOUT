## DiskOUT v0.4.1 — 자동 업데이트 도입

이번 버전부터 DiskOUT 이 새 버전을 스스로 알려줍니다.

### 새로운 기능

- **자동 업데이트**: 24시간 주기로 백그라운드 체크. 새 버전 발견 시:
  - 메뉴바 아이콘 옆에 작은 빨간 점 표시 (조용한 알림)
  - 메뉴 안에 "🔴 새 버전 X.Y.Z 사용 가능" 항목
  - 클릭 → 다운로드 → 검증 → 자동 재시작
- **메뉴 항목 추가**: "업데이트 확인…" — 직접 트리거하고 싶을 때
- 업데이트는 EdDSA 서명 + Apple Code Signing 이중 검증 후에만 설치됨

### 마이그레이션

- v0.4.0 사용자는 이번 한 번만 [GitHub Releases](https://github.com/yooongZa/DiskOUT/releases) 에서 수동으로 v0.4.1 DMG 받아 설치 — 이후 모든 업데이트는 자동.

### 시스템 요구사항

- macOS 13.0 이상 (Apple Silicon 네이티브, Intel 동작)
