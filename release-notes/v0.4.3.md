## DiskOUT v0.4.3 — 일본어 + 중국어 간체 지원

이번 버전은 다국어 확장이 핵심입니다.

### 새로운 기능

- **일본어 (日本語) + 중국어 간체 (中文 简体) 지원 추가**: 한국어 / English 에 이어 4개 언어로 확장.
  - 첫 실행 시 시스템 언어를 자동 매칭 — 일본 사용자는 자동 일본어, 중국 사용자는 자동 중국어
  - 지원 외 언어 (프랑스어 / 독일어 등) 사용자는 영어로 자연 fallback
  - 환경설정 → 일반 → Language 팝업에서 언제든 강제 선택 가능

### 개선

- **언어 변경 즉시 반영**: v0.4.2 까지는 언어 변경 후 재시작해도 한 박자 늦게 적용되는 경우가 있었음. 이번 버전부터 새 launch 마다 즉시 새 언어로 표시됨.
- 메뉴바의 "🌐 언어 변경…" 항목 제거 — 환경설정 패널 한 곳으로 진입점 통일.

### 마이그레이션

- v0.4.0 ~ v0.4.2 사용자: 자동 업데이트가 24시간 안에 알려줍니다. 기존 언어 설정 (한국어 / English / 시스템 따라가기) 은 그대로 유지됩니다.

### 시스템 요구사항

- macOS 13.0 이상 (Apple Silicon 네이티브, Intel 동작)
