FAQ

How do I stop "Disk Not Ejected Properly" on Mac?

Install DiskOUT. It cleanly ejects every external drive the moment your Mac sleeps and remounts them on wake — so the warning never fires.

Is it really free?

Yes. Free download from GitHub Releases, no account needed.

Can I lose data?

DiskOUT uses the standard macOS eject path and tries a clean unmount first. If a disk can't be ejected safely, it leaves it alone and just notifies you.

Does it work on Intel Macs?

The current build is Apple Silicon only (M1/M2/M3/M4), macOS 13 Ventura or later.
